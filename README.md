# ModernWeb Co. Portfolio

A single-page, dark, premium portfolio site inspired by the spacing, typography, project storytelling and minimal navigation style of the provided AIXOR/Framer reference — but with original ModernWeb Co. structure, copy and styling.

## Files
- `index.html` — single landing page
- `styles.css` — responsive styling and hover effects
- `script.js` — smooth anchors, mobile menu, cursor, magnetic buttons, project tilt and reveal animations
- `assets/modernweb-logo.png` — ModernWeb Co. logo

## Form email
The form is configured with FormSubmit and targets `modernwebcoo@gmail.com`.
On first deployment, FormSubmit may require a one-time email activation/confirmation. For production, a serverless function, Formspree, Resend, or Netlify Forms can also be used.

## Deploy
Upload the folder to Netlify, Vercel, GitHub Pages, or any standard static host.
